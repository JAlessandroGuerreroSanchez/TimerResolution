# Manifiesto winget (plantilla)

El archivo `TimerResolutionApp.KalurStudio.installer.yaml` es una **plantilla**: debes sustituir `InstallerUrl` y `InstallerSha256` por los valores reales de tu release (por ejemplo en GitHub Releases) y enviar el paquete al repositorio comunitario [microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs) siguiendo su guía.

Identificador sugerido del paquete: `KALUR.TimerResolution` (ajústalo si publicas con otro nombre).
